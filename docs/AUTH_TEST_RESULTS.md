Тесты создают собственные данные в БД с префиксом `pocket_lms_api_test_`.
Рабочая БД не мигрировалась. Реальное S3 и frontend этой проверкой не покрыты.

Запуск: после подготовки отдельной БД и `scripts/migrate.py`:

```sh
TEST_DATABASE_URL='postgresql://user:password@localhost:5433/pocket_lms_api_test_local' PYTHONPATH=src uv run python -m unittest discover -s tests -p 'test_api*.py' -v
```

Тесты сами устанавливают локальный режим cookie для TestClient. Для рабочей среды
оставьте AUTH_COOKIE_SECURE=true. Порядок обновления сервиса — в AUTHENTICATION.md.
