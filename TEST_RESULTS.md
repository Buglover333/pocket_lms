# Проверка API по API_DESCRIPTION.md

Дата: 24 октября 2026 года.

Результат: 14 тестов успешно выполнены с настоящим PostgreSQL 16 в отдельной
базе pocket_lms_api_test_v2_20261024. Данные прежних ручных проверок не использовались.

Проверены:

- Регистрация, точный набор публичных полей ответа и хранение хеша пароля.
- Невалидная почта, пустые имена, длина и состав пароля, совпадение подтверждения.
- Дубликаты почты с разным регистром и две одновременные регистрации одной почты.
- Вход: user_id, access_token и token_type; неверные реквизиты и отсутствующий хеш.
- Пустые списки в формате {"items": []}.
- Курсы только по активному членству, роли, team_id и исключение посторонних курсов.
- Модули без повторов, исключение курсов без модуля и неактивного членства.
- Профиль без password_hash и yandex_id, в том числе nullable-поля.
- Ошибки 401, 403, 404, 422 у всех трёх защищённых эндпоинтов.
- Отключённый или отсутствующий пользователь, испорченный и истёкший токен.
- POST /app: HTML 200 на временном тестовом файле без подключения к БД;
  503, когда сборки нет. Настоящий frontend ещё не разработан.
- Все шесть эндпоинтов и схемы ошибок в OpenAPI.

Команда (TEST_DATABASE_URL указывает на выделенную тестовую базу):

```sh
PYTHONPATH=src uv run python -m unittest discover -s tests -p test_api.py -v
```

Результат unittest: Ran 14 tests; OK.

Зависимость Starlette выдала предупреждение о будущем переходе TestClient с httpx
на httpx2; на выполнение проверок это не повлияло. Старый tests/test_crud.py
в эту проверку не входил.
