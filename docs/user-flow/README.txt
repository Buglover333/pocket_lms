Pocket LMS — юзер-флоу с эндпоинтами, версия 3, 25.10.2026

Открыть user-flow-v3.html в любом браузере. Все три схемы встроены в файл: переключение ролей, масштаб и пояснения по нажатию. Файл можно отправить коллеге; интернет для просмотра не нужен.

PNG — для вставки на холст или в документ. SVG — для увеличения и редактирования.

Схемы соответствуют исправлениям API ветки endpoints от 25.10.2026. Нереализованные функции выделены жёлтым. Настоящая интеграция S3 ещё требует bucket и тестовой роли.

У запросов POST /auth и POST /register альтернативные условия: вход либо регистрация. При действующей сессии — сразу главная. Методы у одного блока могут быть альтернативами; примечания поясняют выбор.
